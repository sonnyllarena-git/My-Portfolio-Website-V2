Title: Dental Clinic System
Description: A production-grade dental practice management system, currently an offline-first React + TypeScript frontend (Vite, Zustand, React Hook Form + Zod, Radix UI components, Dexie/IndexedDB for local data) covering patient records, scheduling, treatment planning, billing, and inventory. It's architected for a Phase 2 Node.js + PostgreSQL backend, with the schema, architecture, and implementation plan already documented, and has the most mature engineering setup of the four (active CI with lint/build/test/seed-validation jobs, Vitest + Testing Library coverage).

Tech Stack:
Frontend

React 18.3 + TypeScript, built with Vite 5
React Router 6
Zustand 4 (state management, separate stores for workspace/scenario/session)
React Hook Form + Zod (forms + schema validation, via @hookform/resolvers)
Radix UI primitives (Dialog, Dropdown Menu, Label, Select, Tabs) + class-variance-authority, tailwind-merge, lucide-react — a shadcn/ui-style component setup
Tailwind CSS 3 + PostCSS/Autoprefixer, @fontsource self-hosted fonts (Inter, Inter Tight, IBM Plex Mono)
Dexie 4 (wrapper over IndexedDB) — offline-first local data layer with a repository pattern (localRepository.ts, repository.ts, seed data/scenarios)

Tooling / quality

pnpm (lockfile, CI uses pnpm 9)
ESLint 9 + typescript-eslint + eslint-plugin-jsx-a11y + eslint-plugin-react-hooks
Prettier 3
Vitest 2 + Testing Library (React, jest-dom, user-event) + fake-indexeddb for testing the Dexie layer
Custom scripts: validate-seed and audit:coverage (run via tsx)
GitHub Actions CI (active, not just .example): separate lint / build / test / validate-seed jobs on Node 20 + pnpm
