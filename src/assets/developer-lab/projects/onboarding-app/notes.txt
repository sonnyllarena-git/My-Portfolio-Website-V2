Title: Onboarding App
Description: Employee Onboarding/Offboarding Portal - Enterprise platform built from zero to production with real-time platform syncing, 99.9% uptime SLA, and self-service error recovery.
Tech Stack:
Frontend
-React 19
-React Router 7
-Vite 8
-Tailwind CSS 3 + PostCSS + Autoprefixer
-ESLint 10
-JSX 
-prop-types for prop validation

Backend
-Node.js
-Express 4
-node:sqlite (built-in SQLite, used for local dev DB)
-dotenv, cors, uuid, isomorphic-fetch
-nodemon

Planned production stack (documented, not yet implemented)
-Azure SQL (replacing SQLite) via mssql
-Azure Key Vault (replacing .env secrets)
-Azure App Service (hosting, with managed identity + TLS)
-express-rate-limit (rate limiting)
